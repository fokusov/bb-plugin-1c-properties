# Редактор 1С в BB

Плагин «1С» (`1c-properties`) добавляет в поток с рабочей папкой вкладку «1С» и открывает рабочие файлы `.bsl` и `.xml` в Monaco.

- Дерево файлов и метаданных поддерживает EDT, XML-выгрузку Конфигуратора и пообъектную XML-выгрузку.
- Сохраняйте по Ctrl+S, переходите к определению по F12. Поддерживаются UTF-8 и Windows-1251.
- В режиме изменений доступны Git-диффы, отметки просмотренных блоков, откат, индексирование и коммит.
- Действие «Добавить к обсуждению» вставляет путь и диапазон строк в композер этого потока.

Настройки открытия ссылок, пути к Git и таймаута задаются в карточке плагина. Файлы и команды Git выполняются на машине рабочего окружения потока. Агент редактирует файлы своими штатными средствами.

Для перехода с отдельного `bsl-editor` и отката см. [инструкцию](../../docs/editor.md).
